核心功能

四类信息，一处配置

每个页签只做一件事，组合起来就是一次完整整理：改完名字、对齐时间、收拾属性、补上 EXIF。

文件名

模板变量命名、序号补零、查找替换（支持正则）、前后缀、大小写统一。

  • 两阶段重命名，A→B、B→C 不会互相覆盖
  • 扩展名自动补全，无需手写
{date:yyyyMMdd}_{seq:000}

文件日期

创建时间、修改时间、访问时间，走 Windows 原生 API，含真正的「创建时间」。

  • 来源：固定值 / 叠加偏移 / EXIF 回填
  • 也可从文件名解析日期
2024-07-05 09:41

文件属性

只读、隐藏、存档、系统四项属性，每项三态：保持原样 / 置位 / 清除。

  • 隐藏与只读写入前会自动处理权限
  • 写入完成后统一恢复属性
只读 · 隐藏 · 存档 · 系统

EXIF

拍摄时间、数字化时间、DateTime，支持固定值、偏移、回填与清除。

  • 可把 EXIF 拍摄日期回填为文件时间
  • 支持 JPEG / TIFF / WebP
DateTimeOriginal

命名模板变量

写进模板即可自动替换；扩展名会自动补上，模板里无需书写。

{date:yyyyMMdd}目标日期（来自「日期」页规则）
{exifdate:yyyy-MM-dd_HHmmss}EXIF 拍摄日期
{created:...}文件创建时间
{modified:...}文件修改时间
{accessed:...}文件访问时间
{seq}序号，可写 {seq:000} 补零
{stem}原主名
{ext}扩展名
{name}原全名
{folder}所在文件夹名
{width} {height}图片尺寸
{sizekb}文件体积（KB）
{hash8}文件头 MD5 前 8 位
{parent}完整路径

功能特性

批量改文件，最怕改坏

所以它的每一步都留了退路：先给你看会发生什么，动手前后都记日志，出问题能整批撤回。

完全离线

Windows 端本地服务只监听 127.0.0.1；Android 端根本没有声明网络权限。断网也能用，文件不上传。

轻装：14.8 MB / 1.3 MB

Windows 是一个 exe 双击即用，不需要装 Python、不写注册表；安卓安装包只有 1.3 MB。两端都不弹广告。

先预览，后执行

逐条 diff 对照：改名前后、时间变化、属性与 EXIF 改动，冲突和警告会提前标出来。

日志 + 一键撤销

每步成功后立即落盘到 journals/，撤销时按反序还原文件名、时间戳、属性与 EXIF。

两阶段重命名

先把所有文件改成临时唯一名，再改成目标名，彻底避免 A→B、B→C 的链式覆盖。

顺序有讲究

固定按「写 EXIF → 重命名 → 写时间戳 → 写属性」执行：改名与 EXIF 都会刷新修改时间，所以时间必须最后写。

快速上手

四步，一批照片就整好了

第一次启动需要 2–4 秒解压，之后双击即开。界面里四步走完，就是一次完整处理。

  1. 1

    导入照片

    点「选择文件夹」或「选择文件」，也可以直接粘贴路径后点「扫描导入」。需要连子目录就勾上「包含子文件夹」。

  2. 2

    配置规则

    在「文件名 / 文件日期 / 文件属性 / EXIF」四个页签里按需开启。只用其中一项也可以，其余保持原样。

  3. 3

    生成预览

    点「生成修改预览」，逐条核对改名前后与各项改动，确认无误再继续。

  4. 4

    执行 / 撤销

    二次确认后开始写入。任何时候都能打开「操作日志」，一键撤销本次全部改动。

pip install -r requirements.txt
python app.py

常见问题

你可能想问的

点「选择文件 / 选择文件夹」没反应？

对话框直接用 Win32 原生 API 调用，不依赖 tkinter（精简版 Python 常缺 tcl/tk）。若仍无响应，可以直接在路径框粘贴完整路径，再点「扫描导入」。

双击 exe 没有窗口？

窗口基于系统自带的 Edge WebView2 Runtime。Win10/11 一般已预装；若缺失请先安装 WebView2，或用 python app.py 启动查看报错信息。

EXIF 支持哪些格式？

写入支持 JPEG / TIFF / WebP。HEIC、RAW、PNG 会跳过 EXIF 写入并在预览里提示，但不影响改名、日期与属性处理。

改错了能恢复吗？

能。每步成功后都会把操作写入 journals/，在「操作日志」里一键撤销即可按反序还原文件名、时间戳、属性与 EXIF。建议处理前先备份重要照片。

日志存在哪里？

保存在 exe 同目录的 journals/。所以请把 exe 放在可写目录，不要放在 C:\Program Files 下。

需要联网吗？会上传照片吗？

不需要，也不会。Windows 端本地服务只监听 127.0.0.1，不访问外网；Android 端安装包里根本没有声明网络权限，装好之后物理上无法联网。

设为「隐藏」后文件不见了？

隐藏属性会让文件在资源管理器里默认不显示，属于预期行为。所有改动都可撤销；「系统」属性请谨慎设置。

安卓版和电脑版功能一样吗？

改名、修改时间、只读、EXIF、预览、日志与一键撤销两端都有。差异来自系统本身：安卓写不了「创建时间」，没有「存档 / 系统」属性，隐藏用文件名前的「.」代替，访问时间只能显示。完整对照见页面上方的两版能力对照。

安卓版需要什么权限？

需要存储访问权限（Android 11 及以上是「所有文件访问权限」），否则无法改写别人目录里的照片时间与属性。应用不申请网络权限，也不读取通讯录、位置等信息。授权后仍建议先用几张照片试一遍。

手机提示「未知来源应用」装不上？

APK 来自 GitHub Releases，没有走应用商店，系统会拦一次。在提示里选择「仍要安装」，或到「设置 → 应用 → 特殊权限 → 安装未知应用」里允许你的浏览器 / 文件管理器安装即可。
